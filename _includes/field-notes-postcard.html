{%- comment -%} Per-image aspect-ratio override. Default is 4/5 (portrait) from field-notes.css. An image entry with `aspect_ratio: "3/2"` (or "1/1", "4/3", etc.) overrides just that card via inline style — the only valid reason to use inline style here, since the value is data-driven and the alternative would be a per-image CSS class per image. object-fit: cover stays in effect either way. data-slug: a stable, URL-safe key for this image, used by the clap button to namespace its counter (CounterAPI) and its localStorage "already clapd" flag. We derive it from the filename so adding a new image to the gallery auto-provisions a counter with no manual work. The slug strips the extension and collapses spaces/dots to dashes — matches what CounterAPI's slug validator accepts. {%- endcomment -%} {%- assign slug = include.image.filename | split: "." | pop | join: "." | replace: " ", "-" | replace: ".", "-" | downcase -%}
